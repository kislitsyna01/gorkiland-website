# ГоркиLand — сайт компании

Одностраничный сайт на React, TypeScript, Vite и GSAP. Для публикации используется GitHub Pages через GitHub Actions.

## Локальный запуск

Требуются Node.js 22 и pnpm 11.25.0 (указана версия, зафиксированная в `package.json`).

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Обычная production-сборка для корневого домена:

```sh
pnpm build
pnpm preview
```

Сборка с путями для репозитория `gorkiland-website` на GitHub Pages:

```sh
pnpm build:pages
pnpm preview
```

Vite добавляет префикс `/gorkiland-website/` только для `build:pages`; локальная разработка и обычная сборка используют `/`. В приложении пути картинок и логотипов берутся из `import.meta.env.BASE_URL`, а favicon задаёт тот же префикс через `%BASE_URL%`. Шрифты Inter импортируются из npm-пакета и включаются в сборку. Видео из `05_VIDEO/` в текущем интерфейсе не используются.

## Публикация в GitHub Pages

1. В репозитории **`kislitsyna01/gorkiland-website`** откройте **Settings → Pages → Build and deployment** и выберите **GitHub Actions** в поле **Source**.
2. Проверьте remote и активную ветку:

   ```sh
   git remote -v
   git status --short --branch
   ```

3. Соберите Pages-версию, добавьте файлы проекта и просмотрите staged diff:

   ```sh
   pnpm install --frozen-lockfile
   pnpm build:pages
   git add -A
   git diff --cached --stat
   git diff --cached --check
   git diff --cached
   ```

4. Если в diff нет секретов или ненужных файлов, создайте коммит и отправьте ветку `main`:

   ```sh
   git commit -m "Prepare ГоркиLand site for GitHub Pages"
   git push -u origin main
   ```

Push запускает workflow `.github/workflows/deploy.yml`. Результат и опубликованный URL появятся в **Actions** и в **Settings → Pages**. Повторная публикация происходит автоматически после каждого push в `main`; workflow можно также запустить вручную во вкладке **Actions**.

## Безопасная проверка перед push

- Убедитесь, что `git remote -v` показывает именно ваш репозиторий `gorkiland-website`.
- Просмотрите staged diff и список staged-файлов; не отправляйте `.env`, токены, пароли или локальные данные.
- Не используйте `git push --force`. Если на GitHub уже есть история коммитов, сначала синхронизируйте её обычным способом, не перезаписывая удалённую ветку.
- Исходные папки с PDF, видео и рабочими концептами исключены через `.gitignore`; сборка использует опубликованные изображения и логотипы из `public/assets/`.

Для перехода с GitHub Pages на другой домен потребуется согласовать Vite `base`, canonical URL, Open Graph URL и адрес sitemap.

## Материалы и ограничения текущей версии

- Сайт использует оптимизированные изображения и логотипы из `public/assets/`.
- Видео и исходные дизайн-материалы локальны и исключены из репозитория; видео в текущем интерфейсе не используются.
- Партнёрские логотипы основаны на изображениях из макета и не являются векторными оригиналами.
- Форма проверяет поля и согласие, но пока не отправляет данные и не подключена к CRM/API. Переключатель EN сообщает, что перевод готовится.
- Соблюдайте постоянные правила разработки из `AGENTS.md` и сверяйте фирменные решения с брендбуком и материалами проекта.
